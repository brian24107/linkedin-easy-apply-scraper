# LinkedIn Easy Apply Job Scraper (Beginner Project)

This is a simple Python automation tool that opens LinkedIn in your browser, searches for jobs with the "Easy Apply" filter, and saves the job titles, companies, locations, and links to a CSV file.

> ⚠️ This is for **learning purposes only**. It uses Selenium to automate your browser but does not log in or interact with LinkedIn accounts. Use responsibly and don't spam the site.

---

## 🔧 What It Does

- Opens Chrome
- Goes to the LinkedIn jobs search page (with Easy Apply filter on)
- Grabs the job title, company, location, and link
- Saves everything to `jobs.csv`
